# 企业微信工作台自建应用免登 — 前端对接

> 后端已打通 OAuth2 静默授权（snsapi_base）免登链路，本文档供**独立 Vue 前端项目**对接使用。
> 后端改动详见计划文件 `cosmic-vortex-lovelace.md`，关键接口：`POST /api/Auth/login-by-wechatwork`、`GET /api/Wechat/authorize-url`。

## 一、免登流程

```
前端入口加载
  ├ 本地有 token → 直接进入
  └ 无 token
       ├ URL 带 ?code=xxx → POST /api/Auth/login-by-wechatwork { code }
       │     成功 → 存 token → 清除 URL 中 code → 进入
       │     失败 → 走下方授权
       └ 无 code → GET /api/Wechat/authorize-url?redirect_uri=encodeURIComponent(location.href)
             拿到 url → location.href = url（跳企业微信授权页）
             企业微信带 code 回 redirect_uri → 重新进入流程（命中上面「带 code」分支）
```

## 二、后端接口约定

### 1. 获取授权链接
`GET /api/Wechat/authorize-url?redirect_uri={前端回跳地址（URL 编码）}`

返回：`{ "url": "https://open.weixin.qq.com/connect/oauth2/authorize?..." }`

> ⚠️ `redirect_uri` 的 Host 必须在后端 `WeChatWork:AllowedRedirectHosts` 白名单内，否则返回 400（防开放重定向）。

### 2. 免登换登录态
`POST /api/Auth/login-by-wechatwork`

请求体：
```json
{ "Code": "企业微信回调携带的 code" }
```

返回 `ApiResponse<LoginResultDto>`：
```json
{
  "Success": true,
  "Message": "企业微信登录成功",
  "Data": {
    "Success": true,
    "Message": "企业微信登录成功",
    "Token": "Base64令牌(含过期时间)",
    "User": { "Id": "...", "UserName": "wx_xxx", "DisplayName": "张三", "Role": "User", "Email": "..." }
  },
  "Timestamp": "2026-08-07T08:30:00"
}
```

失败（如账号被禁用）：`Success=false`，`Message` 含原因，前端应清除本地 token 并重走授权或提示。

## 三、前端 service 示例（Vue3 + TS + axios）

```ts
// src/api/auth.ts
import request from '@/utils/request'

export interface WeChatWorkLoginDto { Code: string }
export interface UserInfoDto { Id?: string; UserName?: string; DisplayName?: string; Role?: string; Email?: string }
export interface LoginResultDto { Success: boolean; Message?: string; Token?: string; User?: UserInfoDto }
export interface ApiResponse<T> { Success: boolean; Message?: string; Data?: T; Timestamp: string }

export function loginByWeChatWork(code: string) {
  return request.post<ApiResponse<LoginResultDto>>('/Auth/login-by-wechatwork', { Code: code })
}

export function getWechatAuthorizeUrl(redirectUri: string) {
  return request.get<{ url: string }>('/Wechat/authorize-url', { params: { redirectUri } })
}
```

## 四、入口 / 路由守卫逻辑

建议放在 `App.vue` 的 `onMounted` 或 `router.beforeEach`：

```ts
import { loginByWeChatWork, getWechatAuthorizeUrl } from '@/api/auth'

const TOKEN_KEY = 'token'
const getToken = () => localStorage.getItem(TOKEN_KEY)
const setToken = (t: string) => localStorage.setItem(TOKEN_KEY, t)

async function ensureLogin() {
  const token = getToken()
  if (token) return

  const params = new URLSearchParams(location.search)
  const code = params.get('code')
  if (code) {
    const res = await loginByWeChatWork(code)
    if (res.data.Success && res.data.Data?.Token) {
      setToken(res.data.Data.Token)
      // 清除 URL 中的 code,避免刷新重复兑换
      params.delete('code')
      const newUrl = location.pathname + (params.toString() ? '?' + params.toString() : '') + location.hash
      history.replaceState(null, '', newUrl)
      return
    }
    // 失败继续走授权
  }

  // 无 token 且无有效 code → 跳转企业微信授权
  const res = await getWechatAuthorizeUrl(encodeURIComponent(location.href))
  if (res.data.url) location.href = res.data.url
}
```

> 提示：令牌有过期时间（后端 `Auth:TokenExpiryMinutes`，默认 1 天）。前端在收到 401 或接口失败时应清除 token 并重新执行 `ensureLogin()`。

## 五、企业微信管理后台配置

1. **应用管理 → 自建应用** → 设置「应用主页」为前端 H5 地址（如 `https://app.example.com/ww-entry`）。
2. **可信域名**加入前端域名与后端 API 域名。
3. **网页授权及 JS-SDK** → 设置可信域名（与上面一致）。
4. 后端 `appsettings.json` 的 `WeChatWork` 节配置真实 `CorpId / AgentId / AgentSecret`，`AllowedRedirectHosts` 包含前端回跳域名。

## 六、注意事项

- 自动建号默认角色为 `User`；如需差异化权限，可预先在「用户管理」表绑定 `WeChatWorkUserId`，或调整后端 `UserService.LoginByWeChatWorkAsync` 的默认 `Role`。
- 企业微信 `snsapi_base` 仅返回 UserId，无需用户同意，满足免登需求；若将来需手机号等敏感信息，再升级 `snsapi_privateinfo`。
- `用户管理` 表加列 SQL 脚本见后端 `DatabaseScripts/AddWeChatWorkUserIdToUser.sql`（执行前请核对真实生产库中文表名/列类型）。
