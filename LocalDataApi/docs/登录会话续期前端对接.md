# HTTP 生产环境登录会话对接

当前生产环境采用受控内网 HTTP 部署，因此只使用短期 JWT，不使用 refresh token 或 Cookie 自动续期。

## 接口

- `POST /api/Auth/login`、`POST /api/Auth/login-by-wechatwork`：返回 `Data.Token`，有效期 30 分钟。
- `POST /api/Auth/logout`：携带 Bearer Token，撤销当前会话。
- `POST /api/Auth/logout-all`：携带 Bearer Token，撤销当前用户所有会话。

## 前端约定

所有请求携带 Bearer Token。收到任意 401 时，不自动刷新、不重试请求；保留当前编辑内容，提示用户重新登录。退出、改密码、管理员重置密码和账号禁用仍会使现有 JWT 立即失效。

HTTP 会明文传输登录密码和 JWT，仅适用于受控内网/VPN 环境；升级 HTTPS 后再恢复 refresh Cookie 续期方案。
