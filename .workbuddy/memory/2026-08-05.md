3. 脚本务必 `SET XACT_ABORT ON`,否则单条失败不会整体回滚,会出现「主表提交、明细未提交」的部分数据
4. 单条 INSERT...VALUES 上限 1000 行,分批 500 安全

## 工单销控表“物料需求明细”为空修复(完成)

### 问题
前端点击“工单总数”弹窗中，“工单总需求”有数据，“物料需求明细”为 0 条。

### 根因(读前端源码确认)
- 前端文件:`YCDataVue/yclt36-curve-viewer/src/views/PMC/WorkOrderTracking/WorkOrderTracking.vue`
- `handleTotalClick` → `generateMaterialDetail` 调用链路:
  1. `externalProductionService.getExternalProductionBOMList({ 货号: record.货号 })`
  2. 后端 `PmcBomService.GetExternalProductionBOMList`:先按 `货号` 找 `外产_BOM` 父记录,再返回 `父级编号=父记录.编号` 的子记录
  3. 用子记录 `货号` 批量查 `外产_领料`,通过 `父级编号` 反查父领料记录,仅当父领料.`货号`=产品货号时才汇总 `出库数量` 为“已出库数”
- 原测试数据错误:`外产_BOM` 记录把 `父级编号` 指向了工单销控表.`编号`(不是 `外产_BOM.编号`),导致子记录查不到;`外产_领料` 也没有父子结构,导致已出库数汇总失败。

### 修复
- `generate_external_bom`:每个产品生成 1 条父记录(`层=0,父级编号=NULL`) + 2 条子记录(`层=1,父级编号=父记录.编号`)
- `generate_external_pick_material`:每个产品生成 1 条父领料(`货号=产品货号`) + 每个子件 1 条子领料(`父级编号=父领料.编号`)
- 已回滚旧 TEST_ 数据,重新生成并插入;校验:`外产_BOM(父)=500`、`外产_BOM(子)=1000`、`外产_领料(父)=500`、`外产_领料(子)=1000`、无孤立子记录

### 关联表说明
- 此弹窗只直接读 `外产_BOM` + `外产_领料`
- `产品资料`/`产品资料装配`/`产品资料装配清单`/`仓库货品`/`仓库信息` 是另一个接口 `SchedulingAnalysisList` 用的(排产分析页),本弹窗未使用,因此测试数据仍不插入这些大真实表

1. `User` 实体无 RowVersion → 登录失败计数并发下可能丢失更新
2. IMemoryCache 非原子 GetOrCreate(只读快照,无正确性问题)

4. 隔离级别未显式指定(默认 READ COMMITTED,回退事务存在写偏斜窗口)

6. CancellationToken 写路径未传播(有意为之,建议写成约定)
